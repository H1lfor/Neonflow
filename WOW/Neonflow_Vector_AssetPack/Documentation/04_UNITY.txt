UNITY — ИМПОРТ И ПОДКЛЮЧЕНИЕ

1. Импортировать Neonflow_Vector.unitypackage в Unity6 с UGUI. Сохранить .meta:
GUID связывают префабы, PNG, шрифт и клипы. Есть отдельный namespace Neonflow.VectorUI.
Не импортировать Sources/SVG в Assets, если они не нужны в редакторе.
Не тащить в сборку Reference, Previews и документацию.
2. Открыть Scenes/Vector_Presentation. Это навигационная демонстрация.
Кнопки переключают экраны, ползунки/поля кликаются. Значения пока демонстрационные;
выход специально не закрывает редактор; остальные действия подключить к игре.
Для пересборки шаблонов есть Tools > Neonflow Vector > Rebuild presentation assets.
Пересборка ПЕРЕЗАПИСЫВАЕТ поставленные шаблоны. Настраивать свои Prefab Variants
или копии за пределами каталога пакета; не вызывать Rebuild после ручных изменений.
3. Canvas Screen Space Overlay, GraphicRaycaster; CanvasScaler reference1920×1080,
Match .5. Корневой Layout с VectorSafeRoot сохраняет композицию на других пропорциях.
В одном активном UI нужен один EventSystem. В проекте с новым Input System использовать
InputSystemUIInputModule; генератор демо учитывает ENABLE_INPUT_SYSTEM.
4. PNG: Sprite(2D/UI), Single, FullRect, PPU100, alpha transparency, Clamp,
Bilinear, MipMaps off, без потерь для чётких краёв. .meta уже содержат border.
Основной исходник границ — manifest.json, border=[Left,Bottom,Right,Top].
Курсор: Texture Type Cursor, Read/Write, hotspot из Cursor_hotspots.json.
Camera Feed — RawImage, не Sprite. Мир, камера и робот не помещаются в UI-картинку.

9-SLICE И ИЗМЕНЕНИЕ РАЗМЕРА
В PNG есть внутренние границы для растяжения панели. Применять Image.Type=Sliced,
fillCenter=true, preserveAspect=false. Прозрачные углы являются частью изображения.
Параллелограмм, растянутый по высоте с 9-slice, может изменить угол боковой линии.
Поэтому PNG безопасно растягивать по ширине при исходной высоте или равномерно
масштабировать целиком. Для произвольной ширины И высоты использовать VectorCutGraphic:
он заново строит четыре угла и сохраняет cutRatio. В экранных префабах применён он.
Силуэты, курсоры, иконки и покадровые эффекты не нарезать на9 частей.
Маски камеры/полос повторяют нужный контур. Raycast учитывает наклон, поэтому
прозрачный угол соседней кнопки не перехватывает мышь.

ИНТЕГРАЦИЯ HUD
VectorHUDView — только отображение. SetHealth(player01,robot01), SetScore(points,combo),
SetRemaining(seconds), SetAccuracy(percent0..100), SetWindow(phase01),
ShowJudgement(grade,percent), SetCameraTexture(texture). Это не оценщик поз.
Для смены заданий назначать Image.sprite у Body/Pictogram, LeftHand/Pictogram,
RightHand/Pictogram и Caption из Movements_catalog. Силуэт tint Pink на Ivory.
Если соответствующая рука цели опущена: спрятать карточку пальцев и убрать
компонент только из плана ЭТОГО задания. Центр Body не сдвигать.
Отсутствие поднятой руки у игрока не означает, что требование задания можно убрать.
Следующие карточки в макете показывают тело; при необходимости у того же контейнера
показывать маленькие значки рук, сохраняя читаемость и не изменяя активное задание.
Камера: после получения валидных кадров выключить Unavailable, настроить UV/crop,
проверить зеркальность реальным человеком. Права/запуск камеры принадлежат игре.
Ошибка камеры/микрофона — фактический статус, не постоянное предупреждение.

АНИМАЦИИ
Effects prefab содержит Image и VectorFlipbook, реальные кадры уже связаны.
Play() для UI, externalClock + SampleSeconds/Phase для музыкальных эффектов.
Для Animator имеется .anim: клип вешается на тот же объект, где расположен Image.
Wipe ставить самым верхним Canvas, raycast blocker отдельно на весь переход;
смена экранов в закрытом интервале, обязательное завершение при отмене/ошибке загрузки.
Автоматический state machine переходов и озвучку подключает игра.
Поставленная демонстрация не притворяется, что все эти переходы уже реализованы.

ЗВУК
9 коротких WAV: hover/select/confirm/back/start/countdown/pause/perfect/miss.
Подключить в отдельную группу AudioMixer UI. Музыка и эффекты — отдельные группы.
Не проигрывать hover чаще одного раза на изменение выбора; не наслаивать оценки
так громко, чтобы маскировать бит. Звук UI должен быть заметно тише музыки.

SKYBOX
Materials/01..06 — 360° окружения одного процедурного шейдера, без шва по азимуту.
Солнце задаётся угловым радиусом и остаётся кругом при перспективном просмотре.
Назначить RenderSettings.skybox; случайно выбирать один материал перед песней.
VectorSkyMotion клонирует материал для времени сцены и возвращает прежний при выходе.
Для игрового режима menuMode=false, SampleSong(songSeconds,beatPhase) от SongClock.
Для меню menuMode=true; для статичного фона допустим готовый vector_menu.png.
Окружение не даёт геометрию пола/коллизии/освещение модели — это отдельная сцена.

реальные длинные названия; русские Ё/ё; тихий/потерянный микрофон; 30/60/144 FPS;
