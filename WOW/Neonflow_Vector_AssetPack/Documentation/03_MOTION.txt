АНИМАЦИЯ — ОБЯЗАТЕЛЬНАЯ ЧАСТЬ VECTOR

Не оставлять игру статичной. Движение должно объяснять выбор, удар, успех,
ошибку и смену экрана. Используются настоящие кадры с разной геометрией,
а также небольшие перемещения и изменения масштаба живых компонентов.
Нет постоянного хаотического дрожания, белых вспышек и свечения вокруг всего.

ПОСТАВКА
198 прозрачных PNG, 13 атласов, JSON с прямоугольниками кадров, 13 AnimationClip
и 13 префабов эффектов. Кадры не содержат надписей — текст поверх отдельным Text.
SVG каждого кадра доступен в Sources/SVG/Animations/Frames.
Кадры с номером000 и последние кадры одноразовых эффектов пустые намеренно:
они очищают изображение до/после эффекта. Это не повреждённые изображения.

РЕЖИССУРА И ТРИГГЕРЫ
select_sweep: один проход бирюзовой полосы при изменении наведения/фокуса.
Не перезапускать каждый Update и не крутить вечно на выбранной кнопке.
press_slash: один короткий акцент при принятии клика. Действие не ждать до конца
эффекта; повторный клик блокирует состояние навигации, а не длительность кадров.
Кнопка при наведении смещается влево14 px за примерно120 ms, при нажатии
возвращается к4 px; текст и фон двигаются вместе. Уход плавный, без overshoot.
screen_wipe: 18 кадров / 30 FPS = 0,6 с. Кадры8 и9 полностью закрывают экран.
Контент менять один раз на8-м кадре (t=8/30 с), звук запуска нового экрана —
там же. Затем открыть новый экран. Блокировать ввод до окончания перехода.
При низком FPS проверять пересечение порога времени, а не равенство индекса8.
Для ультраширокого окна растягивать только wipe на физический размер Canvas.
beat_pulse: короткий внешний контур возле активного задания; ниже карточки,
не поверх силуэта. Фаза берётся из SongClock, не из Update-счётчика кадров.
perfect/great/good/miss: эффект около нижнего результата после фиксации оценки.
Текст появляется сразу, стоит600–750 ms; сам рисунок заканчивается раньше.
Не переносить judgement на центр робота. Miss не трясёт камеру пользователя.
combo: один акцент около счётчика при заметном рубеже серии (например, каждые10);
рубеж — настраиваемая подача, не новая механика или дополнительный множитель.
victory: появляется с заголовком; спустя350 ms включается блок итоговых чисел.
Счёт можно досчитать за600 ms easeOutCubic; Enter/клик завершает подсчёт сразу.
defeat: короткое более тяжёлое раскрытие; без яркого праздничного акцента.
loading: циклично только пока идёт настоящая загрузка, без искусственной задержки.
hold_scan: слабый акцент под полосой удержания; показывать только когда текущая
поза подтверждена, и только в пределах реального текущего задания.

НЕПОКАДРОВЫЕ ДВИЖЕНИЯ
Открытие меню: кнопки входят с правого смещения48 px и alpha0; длительность
220 ms, задержка между кнопками35 ms, easeOutCubic. Затем остаются спокойными.
Смена песни: выбранная строка смещается80 px влево за160 ms, соседние возвращаются;
левая панель меняет данные через fade80 ms out +120 ms in; без подмены рекордов.
Карточки: при смене задания смещение вверх12 px + alpha0→1 за140 ms; новые
цели уже выставлены логикой. Иконки не морфить между разными жестами.
Очередь: три карточки сдвигаются вверх на170 px за180 ms; следующая приходит снизу.
HP: немедленно изменить фактическое значение; видимое заполнение догоняет
за180 ms. Красный след урона задерживается90 ms и догоняет за220 ms.
Полоса восьми ударов движется непрерывно по музыкальному времени.
Совпадение может сглаживаться только для отображения (пример60–100 ms);
сглаженные UI-числа не использовать как вход оценки жеста.
Лого на титуле: очень лёгкое дыхание масштаба1.00–1.012 за4 с; нажмите любую
кнопку — alpha .65–1 за1,6 с. Не качать всё меню и не размывать текст.
Skybox: медленная сетка .8 условной единицы/с, сила подсветки на бит до12%.
Робот: плавные переходы поз, микроопора корпуса, поворот головы к игроку,
акцент плечами в такт; правильная поза читается до целевого удара. Ошибки робота
должны иметь отдельные читаемые состояния, а не случайную тряску костей.

ДВА ЧАСОВЫХ ИСТОЧНИКА
UI-эффекты используют unscaled time, поэтому меню паузы продолжает работать.
Игровые эффекты используют песенное время, замороженное на паузе и восстановленное
после resume. VectorFlipbook.externalClock=true: вызывать SampleSeconds(elapsed)
или SamplePhase(phase) из SongClock. Сам компонент не добывает AudioSettings.dspTime.
На seek/retry обнулить эффекты предыдущего запуска; не продолжать старые вспышки.
Пауза замораживает игровую полосу, удержание, beat-pulse, мир и робота.
Пропущенные кадры не должны сдвигать логику: индекс=floor(elapsed×fps).
Не оценивать попадание по AnimationEvent или достижению конца UI-полосы.

УМЕНЬШИТЬ АНИМАЦИЮ
Сохранять мгновенную смену цвета/фокуса, смысловые HP, проценты и полосу времени.
Отключить вспышки, движения фона, sweep и подпрыгивания. Переход заменить fade120 ms.
Режим должен отключать лишь декор, не скорость игры и не распознавание.

АТЛАСЫ И ПАМЯТЬ
У каждого атласа padding2 px, JSON хранит x,yTop и yUnity. Для Sprite.Create
использовать yUnity; pivot=(.5,.5), pixelsPerUnit=100. MipMaps off, Clamp, Bilinear.
Отдельные кадры и атлас — альтернативы. Не загружать оба варианта одной анимации
одновременно. Поставленные префабы используют отдельные кадры; атласы пригодятся
для оптимизированного загрузчика/SpriteAtlas. Не паковать весь каталог в Resources.
Кадры читать из ссылок/Addressables. Эффекты переиспользовать, не Instantiate на удар.
AnimationClip и VectorFlipbook не должны одновременно менять Image.sprite.
