ИНТЕРФЕЙС — ТЕКСТ, СОСТОЯНИЯ И ЧИТАЕМОСТЬ

На кнопках: Играть / Настройки / Обучение / Выйти / Назад / Продолжить /
Повторить / К выбору трека / Отмена / Готово. Коротко и по делу, без лозунгов.
Для этого Vector-пакета единое название экрана — «Выбор трека»; не смешивать
в нём «выбор песни», «аудиобиблиотеку» и «музыкальный хаб».
Титул: NEONFLOW и «Нажмите любую кнопку, чтобы продолжить».
Подписи HUD: Вы, Робот, Очки, Комбо, Далее, Совпадение: {value}%.
Визуальный верхний регистр допустим только для компактных меток HUD, не для
целых абзацев. Крупные кнопки остаются в обычном регистре.
Английские исключения: NEONFLOW, Victory/Defeat, Perfect/Great/Good/Miss,
Practice Mode, BPM, исходные названия песен/авторов, подписи жестов сверху справа.
Не писать PLAY, NEXT, YOU, ENEMY, SCORE вместо русских меток.

НЕ ДОБАВЛЯТЬ
Мотивационные слоганы, «Покори ритм», «Твой путь начинается здесь», обещания
про уникальный опыт, технические подписи нейросети в HUD, выдуманные онлайн-места,
аватарки случайных людей и искусственную историю достижений.
Свободное место допустимо. У пустого списка есть честное состояние.

СОСТОЯНИЯ
Кнопка: normal / hover / pressed / selected / focus / disabled. Disabled не
реагирует на мышь/клавиатуру/голос и не проигрывает подтверждение.
Песня: selected не обязана совпадать с hover. Keyboard focus не теряется при
уходе мыши; подсветка обоих состояний допустима, если выбранный трек однозначен.
Поле: пустое, ввод, focus, disabled. Placeholder пропадает при вводе.
Громкость: реальное значение и процент меняются вместе; значения сохраняются.
Камера: запрос доступа → запуск → кадр получен → отслеживание → частичная потеря →
нет кадра. «Камера не подключена» показывается только когда камеры действительно нет.
Для недостаточного обзора: «Поднимите руки в кадр». Для потерянного трекинга:
«Не видно руку» / «Не видно плечи» без грубой остановки песни.
Ошибка загрузки: «Не удалось загрузить трек» + «Повторить» и «Назад».
Микрофон отключён: «Микрофон недоступен»; остальные способы управления работают.
Пустые результаты: «Пока нет результатов». Пустой поиск: «Ничего не найдено».
Practice Mode обозначен явно до старта; не смешивать такие записи с обычными.

ДЛИННЫЙ ТЕКСТ
Заголовок строки трека максимум две строки; исполнитель одна. Если не помещается,
использовать многоточие, полный текст — в левой панели. Не уменьшать шрифт до пыли.
Зона BPM фиксирована справа и никогда не сдвигается названием.
Статистика максимум разумной длины: большие значения очков группировать пробелами;
при переполнении заранее предусмотренная размерная ступень, а не выход за плашку.
Сообщения обучения помещаются в заданный блок, без декоративных вступлений.
Проверить Ё/ё, знаки %, двоеточие, тире, русские пробелы и десятичную запятую.
Звёзды сложности предпочтительно рисовать спрайтом star, число — отдельным текстом.
UI_TEXTS_RU.json из предыдущей подготовки включён для сохранения словаря;
точные названия и регистр этого пакета задаются Layouts.json и этим файлом.
При интеграции обновить строки словаря, а не одновременно использовать две версии.
