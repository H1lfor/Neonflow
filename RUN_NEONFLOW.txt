NEONFLOW — запуск

Windows 10/11 x64: распакуйте Builds/Neonflow-Windows.zip и откройте Windows/Neonflow.exe.
Локальная сборка также находится в Builds/Windows. Сохраняйте всю папку Windows:
Neonflow_Data, UnityPlayer.dll и Recognition нужны рядом с приложением.
Сеть, установленный Python и ручной запуск распознавания не нужны.
Разрешите доступ к камере и микрофону в системе. Проверку с человеком пока
не выполняли: приёмку всех поз/пальцев/голосовых команд необходимо провести.

Unity: 6000.6.6f1. Откройте Assets/Neonflow/Scenes/Neonflow.unity и нажмите Play.
Neonflow / Prepare project пересоздаёт только сцену Neonflow и каталог ресурсов.
Neonflow / Run core checks — проверки правил; отчёт TestResults/core-checks.txt.
Neonflow / Build Windows — сборка. Затем python Tools/Recognition/package_windows.py.

Первый запуск: титульник → Играть → Выбор персонажа → Калибровка → Выбор трека.
У Light Robot — подъёмы рук, движения в стороны и диагонали; point, peace, three,
l_shape, point_side. У Solid Robot — arms_t, elbows_up, cross_chest, clap,
shoulders_up/down; open, fist, four, thumb_up, rock.
У каждого по 6 поз и 5 жестов кистей; наборы не пересекаются. Выбор запоминается.
Кнопка с именем в выборе трека меняет персонажа. Повтор песни сохраняет выбор.
Новые результаты помечаются Light/Solid, старые сохраняются без переименования.
Голосовое «играть» на экране персонажей выбирает карточку с фокусом.
Сядьте или встаньте так, чтобы плечи и поднятые кисти помещались в изображении.
После распознавания оставайтесь в кадре 3 секунды: калибровка завершится сама.
Если тело или кисть пропадёт, отсчёт начнётся заново. Нажимать «Готово» не нужно.
Правый край подсказки соответствует вашей правой руке. Ноги не оцениваются.
Поза фиксирована на 8 ударов; примите её заранее и удерживайте до конца шкалы.
Процент «Совпадение» под камерой стал ещё мягче: по сравнению с прошлой сборкой
40% → 50%, 60% → 75%, 80% → 100% при видимых требуемых руках и кистях.
Эта шкала применяется и к очкам, и к удержанию, и к лечению.
Итоговая точность от 50% восстанавливает HP: 50% — +0,5, 80% — около +4,9,
100% — +10. Лечение один раз за окно, максимум 100 HP; ниже 50% — урон.
Escape или кнопка Пауза останавливает музыку и окно. Голосовые команды:
«пауза», «продолжить», «повторить», «назад», «играть».
В настройках вкладки «Звук», «Камера», «Управление»: раздельная громкость,
выбор камеры/микрофона, включение голоса и уменьшение анимации.
Нажатие на название устройства переключает доступные устройства.
В выборе трека доступны поиск и прокрутка всех 11 песен.
Practice Mode использует те же правила без раннего проигрыша.

Сохранения: %USERPROFILE%/AppData/LocalLow/Neonflow/Neonflow/neonflow-v1.json.
Есть резервная копия .bak. Видео и аудио игрока не сохраняются.
Тренировочные и незавершённые попытки отмечены в JSON и исключены из
таблицы обычных завершённых результатов. Автотесты используют TestResults.

Если распознавание недоступно: Повторить попытку на экране камеры либо
повторно выбрать устройство в настройках. Ошибка микрофона не заменяет камеру
и не должна блокировать кнопки. При потере трекинга во время песни нет автопаузы.

Восстановление зависимостей на Windows: Tools/Recognition/setup_windows.ps1
(сеть нужна только разработчику при восстановлении). Закреплённые версии —
Tools/Recognition/requirements-windows-lock.txt, модели — models-lock.json.

macOS: Builds/Neonflow-macOS.zip, внутри macOS/Neonflow.app.
Требуется macOS 14.6 или новее. Universal-сборка для Apple Silicon и Intel;
оба нативных окружения распознавания находятся внутри приложения.
Переносите ZIP и распаковывайте на Mac для сохранения прав исполнения.
Unity/Python и скачивание моделей на компьютере игрока не нужны.
Это разработческая сборка без Developer ID/notarization. Первое открытие может
потребовать явного разрешения в настройках безопасности macOS; глобальное
отключение системной защиты не требуется. Фактический запуск, разрешения
камеры/микрофона и звук на Mac пока не проверены.

Для разработчика: python Tools/Recognition/prepare_mac_runtime.py, затем
Neonflow / Build macOS с установленным Mac Build Support Mono.
MacRuntimeBuild включает окружения только в Mac-сборку до финализации .app.
Архив: python Tools/package_releases.py macOS. package_mac.sh оставлен как
прежний альтернативный способ упаковки worker на самом Mac.

Интерфейс — оригинальный светлый Vector из WOW: непрозрачные светлые
наклонные панели, тёмный текст, бирюзовые и розовые акценты.
Окно камеры расширено; весь кадр показывается без обрезки и растяжения.
Поля зависят от пропорций камеры. Расстояние до камеры подберите так,
чтобы обе руки помещались в её физический угол обзора.
Проверяемые форматы экрана: 16:9 и 16:10. 21:9 исключён автором.

Ограничения и фактически выполненные проверки: AcceptanceReport.txt,
DevelopmentProgress.txt, TechnicalDecisions.txt и TestResults. Тайминги всех песен ещё требуют проверки
на слух в начале, середине и конце; исходные BPM/offset не изменялись.
