NEONFLOW — ТУТОРИАЛ ДЛЯ ИИ-РАЗРАБОТЧИКА
========================================

ОБЯЗАТЕЛЬНОЕ ПРАВИЛО: ОПУЩЕННАЯ РУКА = БЕЗ ЖЕСТОВ ПАЛЬЦАМИ
Пользователь играет перед камерой, которая видит верхнюю часть тела.
Когда руки опущены, кисти могут уйти за нижнюю границу кадра, и пальцы
плохо считываются. В такой позе нельзя назначать жесты пальцами.

1. При создании карты движений не комбинируй опущенную руку с заданием
   на пальцы этой же руки. Например, SHOULDERS DOWN + FIST обеими руками
   — недопустимое сочетание. Для SHRUG UP с опущенными кистями действует
   то же правило: подъём плеч не означает, что кисти попали в кадр.
2. Правило применяется отдельно к левой и правой руке. Если поднята
   только левая, жесты допустимы только для неё; на опущенной правой
   не должно быть ни подсказки жеста, ни проверки пальцев. И наоборот.
3. Пока конкретная рука опущена, убери относящуюся к ней карточку пальцев,
   отключи проверку этого жеста и его вклад в оценку. Не показывай MISS
   за нераспознанные пальцы в позе, которая предусматривает опущенные руки.
   Оценка разрешённых движений плеч и рук продолжает работать отдельно.
4. Даже для поднятой руки жест назначается только если кисть целиком
   находится в кадре и её ключевые точки распознаются достаточно стабильно.
   Кисть у края кадра, перекрытая другой рукой или с плохим трекингом,
   не должна порождать случайные результаты распознавания пальцев.
5. Исчезновение кисти само по себе НЕ доказывает, что рука опущена.
   Различай состояния ArmLowered, HandTracked и TrackingLost.
   Если игрок должен держать руку в кадре, но трекинг потерян, сообщи
   об этом отдельно и не подменяй отсутствие данных распознанным жестом.
6. Возвращай подсказку пальцев лишь на допустимом участке карты после
   стабильного возвращения кисти в кадр. Пороги уверенности и длительность
   подтверждения сделай настраиваемыми и проверь на реальной камере.

ЛОГИКА ДЛЯ КАЖДОЙ РУКИ
fingerCueAllowed = targetPoseAllowsFingerCue
                AND NOT armLowered
                AND handFullyVisible
                AND handTrackingStable

ПОДСКАЗКИ ТЕКУЩЕГО НАБОРА
SHRUG UP и SHOULDERS DOWN: кисти опущены, жесты пальцами запрещены обеим рукам.
DIAGONAL LEFT: жест допускается только для поднятой левой руки.
DIAGONAL RIGHT: жест допускается только для поднятой правой руки.
Остальные позы сами по себе не запрещают подсказки пальцев, но проверка
видимости и качества трекинга обязательна в любом случае.
Например, при CLAP или CROSS ARMS кисти могут перекрывать друг друга.
Соответствие left/right задано по зеркальной подсказке для игрока.

ГРАФИКА
Используй 12 поз рук/плеч и 10 жестов кисти из этого пакета.
Стиль строго плоский 2D: сплошная заливка, без 3D, градиентов и свечения.
Фигура показывается только до талии. Подписи на английском, сверху справа.
Бокс, пиктограмма и текст — отдельные элементы. Бокс масштабируется через
9-slice; пиктограмма сохраняет пропорции. Для противоположной кисти отражай
только картинку, а не подпись и всю карточку.

ФАЙЛЫ
Машиночитаемые ограничения: Data/FingerCue_rules.json в папке Unity-ассетов.
Копия правил лежит рядом с этим туториалом в корне архива.
Movements_catalog.json содержит fingerCueAllowedHands для каждой позы.

Это требования для разработки и данные для валидации карт. Сам ассетпак
не включает модель распознавания, её обучение или реализацию этих правил
в игровом коде; ИИ-разработчик должен явно подключить эту проверку.
