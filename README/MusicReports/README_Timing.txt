NEONFLOW — ПЕРВАЯ ДОЛЯ И СИНХРОНИЗАЦИЯ

В архиве 11 прежних MP3 и обновлённые данные BPM + начала ритма. Программы проверки BPM нет.

КАКОЕ ЧИСЛО БРАТЬ В ИГРУ
В TrackTiming.json поле firstBeatOffsetSeconds — время первой выбранной ритмической опоры от начала MP3, в секундах.
Это рабочая точка, от которой считать доли. Во вступлении до неё может быть звук и более тихие доли.
Это НЕ время первого ненулевого аудиосэмпла и НЕ гарантия первой сильной доли такта.
firstBeatOffsetMs — та же точка в миллисекундах. Не перепутай миллисекунды и секунды.
gridPhaseSeconds — смещение той же равномерной сетки в пределах одной доли (от 0 до 60/BPM).
Для нарастаний эти значения отличаются на целое число долей: это нормально.

ФОРМУЛА
beatTimeSeconds = firstBeatOffsetSeconds + beatIndex * 60.0 / bpm
beatIndex = 0 для первой указанной опоры, 1 для следующей, и так далее.
Например, Neon Odyssey: ~1.778 с, ~2.239538 с, ~2.701077 с при 130 BPM.
Текущая дробная позиция в долях:
beatPosition = (songTimeSeconds - firstBeatOffsetSeconds) * bpm / 60.0
До выбранной первой опоры beatPosition отрицателен.
gridPreviewSeconds содержит первые 8 РАСЧЁТНЫХ точек этой сетки, а не отдельные измеренные удары.

UNITY
Для запуска можно использовать AudioSource.PlayScheduled(startDspTime), где startDspTime — время запуска по AudioSettings.dspTime.
Тогда songTimeSeconds = AudioSettings.dspTime - startDspTime.
Это выражение применимо к обычному непрерывному воспроизведению без паузы, перемотки и изменения скорости; для этих действий отсчёт надо корректировать.
Официальная документация: https://docs.unity.com/en-us/engine/6000.6/script-reference/unityengine/audiosource/playscheduled
При изменении начала аудиофайла offset нужно пересчитать. Задержку устройства и ввода калибруй отдельно от музыкального offset.

ТОЧНОСТЬ И ПРОВЕРКА
Данные получены из аудиосигнала: огибающие атак с шагом около 2 мс, сетка заданного BPM, сравнение с двумя моделями долей, визуальная проверка формы волны вступлений.
Это НЕ ручная проверка на слух и НЕ гарантия точности до 1 мс. Три знака после запятой задают единицы хранения, а не достоверность.
При плавных вступлениях нельзя однозначно выбрать «первый слышимый удар» по одному порогу громкости. Здесь дана выбранная опорная доля; в примечаниях указаны неоднозначные случаи.
Особенно проверь On The Road To The Eighties_59sec, 80s Synth, Futuristic Pulse, Brain Implant и Synthetic drive 1 minute.
Для Futuristic Pulse исправлена прежняя фаза ~0.428 с: выбран пульс около 0.197 с, на другую половину доли. BPM не менялся.
Все BPM взяты из предыдущего отчёта; ни BPM, ни offset не считаются подтверждёнными пользователем.
